# 对比上游：新增功能与优化清单

> 对比对象：**上游** [`wy51ai/floorplan-3d`](https://github.com/wy51ai/floorplan-3d) 的 `index.html`
> （2,675 行 / 176,450 字符 / 单文件，无构建）vs **本项目** `decoration-studio`（148 个源文件 / 25,764 行）。
>
> 数据来源：GitHub raw 抓取 + 本地 `src/**` 统计，**均为实测**，非文档转述。
> 核实时间：2026-10-21。

## 1. 新增功能（上游完全没有）

> 每一项都有对应的实现文件，行数为实测。

### 1.1 导出能力：从 2 种 → 8 种

上游只有 **PNG + JSON**。本项目新增：

| 格式 | 实现文件 | 行数 | 说明 |
| --- | --- | --- | --- |
| **CSV** | `extras/lib/export-csv.ts` | 85 | 报价单 / 方案对比 / 校验告警三种 CSV |
| **XLSX** | `extras/lib/export-xlsx.ts` | 198 | 带样式与公式，多 sheet |
| **DXF** | `extras/lib/export-dxf.ts` | 203 | CAD 通用，含图层命名 |
| **SVG** | `extras/lib/export-svg.ts` | 180 | 矢量图纸，可再编辑 |
| **打印图册** | `extras/lib/print.ts` + `print.css` | 132 | 打印 → 另存为 PDF |
| PDF（接口） | `extras/lib/export-pdf.ts` | 62 | 仅注入点，**未启用**（见 §4） |

配套：`ExportMenu.vue`（430 行）统一导出菜单，`download.ts`（56 行）文件下载。

### 1.2 多方案对比

| 文件 | 行数 | 能力 |
| --- | --- | --- |
| `extras/PlanCompare.vue` | 222 | 并排对比 2+ 方案 |
| `extras/lib/compare.ts` | 60 | 差异计算（面积/材料/家具） |
| `extras/lib/metrics.ts` | 212 | 指标提取 |

对比维度：面积、材料用量、家具数量、差异摘要（以第一个为基准）。

### 1.3 平面图自动校验

| 文件 | 行数 | 能力 |
| --- | --- | --- |
| `extras/lib/validate.ts` | 361 | 5 类规则 + 阈值配置 |
| `extras/ValidationPanel.vue` | 105 | 告警列表，点击定位 |

规则：家具穿墙、压门洞、遮挡通道、房间无家具、尺寸异常。
**实测**：默认三室两厅户型产生 **26 错误 · 3 提示 · 1 提示**，每条带具体数值
（如「家具穿墙『双人床』与外墙重叠 46mm（超过 30mm 容差）」）。

> ⚠️ 上游 `index.html` 里有一个 `validateSel()`，但那是「清理失效选中」，
> 与平面图校验无关——已核实，不是同一功能。

## 2. 优化项（上游有，但本项目做得更好）

### 2.1 架构：从全局单例 → 分层可测

| 方面 | 上游 | 本项目 |
| --- | --- | --- |
| 状态管理 | 全局可变 `state` 对象 | Pinia 5 个 store（plan/layout/ui/theme/toast），1,317 行 |
| 类型安全 | 无 | TS 严格模式 + 11 个类型文件 |
| 模块边界 | 无约束 | ESLint 强制 B1–B9（features 互不 import 等） |
| DOM 操作 | 24 处 `querySelector` 手写 | 33 个 Vue 组件响应式渲染 |
| 事件绑定 | 32 处裸 `addEventListener` | 8 处（其余 `@vueuse/core` 自动解绑） |
| 3D 端口 | `window.View3D` 全局单例 | `utils/scenePort.ts` 依赖倒置注册表 |

### 2.2 配色：从「单套 3 色」→「3 套 47 令牌 + 对比度断言」

**修复了上游两处 WCAG 不达标**（实跑 colorjs.io 才暴露）：

| 令牌 | 上游值 | 上游对比度 | 本项目值 | 本项目对比度 |
| --- | --- | --- | --- | --- |
| `--muted`（日间正文） | `#8a8174` | **3.78:1** ❌（AA 要求 4.5） | `#6d6459` | **5.71:1** ✅ |
| 白字压 `--accent` | `#b5653a` | **4.30:1** ❌ | `#9c4f28` | **5.89:1** ✅ |
| `wall-partition`（夜间） | — | 上游无夜间主题 | `#68717f` | **3.35:1** ✅ |

**新增 136 项对比度断言**（`theme/contrast.spec.ts`），把「配色优化」从主观审美变成可回归的测试。

### 2.3 3D 配色：从 54 处 `mat('#...')` 硬编码 → 单一来源

| 方面 | 上游 | 本项目 |
| --- | --- | --- |
| 材质颜色 | **54 处 `mat('#...')` 硬编码**（全文件 240 行含 hex，共 393 处出现） | 集中在 `theme/material-palette.ts`（164 行） |
| 主题联动 | 无 | 背景/地面/曝光/半球光/太阳色/`envK` 全部随主题变 |
| 约束 | 无 | `features/scene3d/**` **禁止出现 hex**，由 `verify.mjs` 机器校验 |

### 2.7 缺陷修复（本项目发现并修的）

**上游不达标：**

| # | 缺陷 |
| --- | --- |
| 1 | `--muted` 对比度 3.78:1（低于 WCAG AA） |
| 2 | 白字压 `--accent` 对比度 4.30:1 |

**重构过程引入、已修复：**

| # | 缺陷 | 严重度 |
| --- | --- | --- |
| 3 | 3D 装饰色全部变白（three.js 不支持空格分隔 hsl 语法） | 高 |
| 4 | 复式户型 3D 当前层几何不建（用了 `plan` 而非 `plan.levelData`） | 高 |
| 5 | 切户型后 3D 场景不重建（签名在非活跃期被提前更新） | 高 |
| 6 | 亮点功能入口全部不可达（`registerViewMount` 从未调用） | 高 |

> 第 3–6 条都补了防护测试，并做**变异验证**（重新注入缺陷后测试会失败）。

## 3. 保留的原有功能（行为等价迁移）

这些上游有、本项目也有的，做了行为保真迁移（详见 `docs/MIGRATION.md`）：

- 2D 平面编辑：选择/测量/拆改、拖拽移动、旋转、缩放、贴墙吸附
- 60 件家具库（6 分类 / 45 唯一类型）
- 3D 场景：鸟瞰/漫游、门开关、剖切墙、日照滑杆、夜景、CSS2D 房间标签
- 触屏摇杆、双指缩放
- 房间面积统计、材料造价（8 种材料 × 5% 损耗）
- 撤销/重做（双栈隔离：布置 150 / 结构 80）
- localStorage 自动保存
- 中英双语切换
- 快捷键体系（21 项键盘 + 触屏手势）

## 5. 一句话总结

| 维度 | 上游 | 本项目 |
| --- | --- | --- |
| **形态** | 单文件 demo，打开即用 | 现代工程，可维护可测试 |
| **功能** | 核心编辑 + 2 种导出 | 核心编辑 + **8 种导出** + 对比/校验/命令面板/主题 |
| **质量** | 无测试、无类型、无构建 | 226 单测 + 7 E2E + 20 静态闸门 + TS 严格模式 |
| **配色** | 单套 3 色，2 处不达标 | 3 套 47 令牌，136 项对比度断言 |
| **无障碍** | 无 | 键盘可达 + 读屏 + 焦点陷阱 |
| **许可** | MIT | MIT（保留上游署名） |

**代价**：从 1 个文件变成 148 个文件、2,675 行变成 25,764 行（约 ×9.6）。
换来的是**可维护性、可测试性、可扩展性**——这也是本项目的学习目标本身。
