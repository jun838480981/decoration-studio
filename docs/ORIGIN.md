## 0. 一句话结论

本项目是**个人学习项目**：把一份 MIT 许可的单文件户型设计工具（`index.html`）重构为
Vue 3 + Vite + TypeScript 工程，用于学习现代前端工程化、three.js 3D 渲染、状态管理与主题系统。
**上游为 MIT 许可，本项目同样以 MIT 发布，合规。**

## 2. 与本地源文件的关系（已核实）

本项目迁移的源文件是仓库根目录的 `装修设计.html.bak`（2665 行 / 185,771 字节）。

**与上游 `index.html`（2675 行 / 185,528 字节）的关系**：

| 检查项 | 结果 |
| --- | --- |
| 文件体积 | 185,771 B vs 185,528 B（相差 243 B） |
| 行数 | 2665 vs 2675（相差 10 行） |
| SHA256 | **不同**（`7008e374…` vs `9fa6cbab…`） |
| 核心特征串 | `huxing-design-v1` / `--accent:#b5653a` / `case 'plant'` / `双人床 1.8m` / `ROOMS` / `WALLS` / `MATS` —— **全部一致** |

**结论**：本地 `.bak` 是上游 `index.html` 的**轻微改动版本**（同源，非完全相同）。
差异量级（10 行 / 243 字节）属于局部调整，不构成独立作品。

> 本地另有一份 `装修设计.html`（3895 行 / 265,186 字节），是在 `.bak` 基础上继续演进后的版本
> （新增多方案管理、结构编辑等能力，见 `docs/ORIGINAL-FEATURES.md` §9）。
> 本项目的功能基线以它为准，`.bak` 作为差异核对基准。

## 3. 使用目的

**个人学习**。具体学习目标：

| 学习主题 | 在本项目中的体现 |
| --- | --- |
| 单文件应用 → 现代工程化重构 | 3895 行 `index.html` → 141 个 TS/Vue 模块，Vite 构建 |

| three.js 3D 渲染 | 程序化建筑与家具建模、相机控制、资源释放 |
| 设计系统 / 主题令牌 | 3 套预设 × 47 令牌，colorjs.io 做 WCAG 对比度断言 |

| 无障碍 | 焦点陷阱、键盘可达、ARIA |
| 工程质量 | ESLint 模块边界规则、依赖白名单、变异测试验证 |

## 5. 与上游的功能差异

本项目**不是**简单的「换框架重写」，而是在迁移过程中做了明确的增删改。完整对照见
[`docs/MIGRATION.md`](MIGRATION.md)，要点：

### 5.1 保留（行为等价）

2D 平面编辑、60 件家具库、3D 鸟瞰/漫游、拆改墙体、测量、房间面积与材料造价、
中英切换、PNG/JSON 导出、localStorage 自动保存、撤销重做、快捷键体系。

### 5.2 改进

| 方面 | 上游 | 本项目 |
| --- | --- | --- |
| 主题 | 单套 `:root`（3 个色值） | 3 套预设 × 47 语义令牌，WCAG 对比度**单测断言** |
| 对比度 | 无校验（`--muted` 仅 3.78:1，不达标） | 修复至 5.71:1；136 项断言 |
| 3D 配色 | 40+ 处硬编码 `mat('#...')` | 收敛到 `theme/material-palette.ts` 唯一来源，随主题联动 |
| 架构 | 全局可变单例 + 手写 DOM | Pinia store + 组件，契约有机器闸门 |
| 导出 | PNG / JSON | 增加 CSV / XLSX / DXF / 打印图册 |
| 工程化 | 无构建、无类型、无测试 | Vite + TS + 226 单测 + 7 E2E + 20 项静态闸门 |

### 5.3 新增亮点功能

上游没有、本项目新增：

- 多方案并排对比 + 差异摘要
- 平面图自动校验（家具穿墙 / 压门洞 / 遮挡通道等，实测 30 项告警）
- 撤销历史面板（可视化时间线 + 跳转）
- 命令面板（`Ctrl/⌘+K`，30 条命令）
- 主题预设切换（日间 / 夜间 / 高对比）
- 3D 剖切墙、夜景、日照滑杆（上游已有部分，本项目补齐联动）

### 5.4 明确未迁移

| 项 | 理由 |
| --- | --- |
| `window.View3D` 全局单例 | 反模式，改为 `utils/scenePort.ts` 注册表 + 挂载位 |
| 手写 `tr(zh,en)` + `data-en` DOM 改写 | 改用 `vue-i18n` |
| `body.m3d` 类名驱动视图切换 | 改用 store 状态 + 组件挂载位 |
| 单文件 3895 行结构 | 拆为 141 个模块 |

## 6. 迁移中修复的上游缺陷

迁移过程中发现并修复的问题（详细记录见 `docs/MIGRATION.md` §12）：

| # | 缺陷 | 性质 |
| --- | --- | --- |
| 1 | 夜间主题 `wall-partition` 对比度仅 2.93:1（低于 WCAG 3:1） | 上游配色不达标 |
| 2 | 日间 `--muted` 仅 3.78:1 | 上游配色不达标 |
| 3 | 3D 装饰色全部变白（three.js 不支持空格分隔的 hsl 语法） | **迁移引入**，已修复 |
| 4 | 复式户型 3D 当前层几何不建（用了 `plan` 而非 `plan.levelData`） | **迁移引入**，已修复 |
| 5 | 切户型后 3D 场景不重建（签名在非活跃期被提前更新） | **迁移引入**，已修复 |
| 6 | 亮点功能入口全部不可达（`registerViewMount` 从未调用） | **迁移引入**，已修复 |

> 第 3–6 条是重构过程引入的缺陷，不是上游的问题。已全部修复并补上防护测试
> （含变异测试验证：重新注入缺陷后测试会失败）。
